# PaperLens — 文獻對照閱讀器

Chrome 擴充功能。左邊原文、右邊繁體中文，**圖片、表格、公式、排版原樣保留，只換語言**；
可以用螢光筆畫重點、手寫圈選、貼便利貼、寫心得、叫 AI 解釋這段在講什麼，最後整篇匯出成左右對照的 PDF。

**網頁文獻和 PDF 檔都支援**。PDF 用內建的 pdf.js 渲染，左右兩欄畫的是**同一張頁面**，右欄只把文字就地換成中文 —— 圖、公式、排版天生 1:1。

完整操作說明看 [使用說明書.md](使用說明書.md)。

不需要註冊、不需要付費、沒有額度限制。

---

## 安裝（3 步，約 30 秒）

1. Chrome 網址列輸入 `chrome://extensions`
2. 右上角打開 **開發人員模式**
3. 點 **載入未封裝項目**，選擇這個 `PaperLens` 資料夾

裝好後工具列會出現一個靛藍色圖示。

> 第一次會要求「讀取及變更您在所有網站上的資料」——因為它必須能在任何期刊網站上重排版面與抓取文字。所有內容都在你的電腦上處理，只有送去翻譯的那幾段文字會離開瀏覽器。

### 兩件一定要注意的事

1. **這個資料夾不能搬走或刪掉。** Chrome 每次啟動都會從這個路徑重新讀取，路徑一變擴充功能就失效。
2. **它現在放在 OneDrive 底下。** 如果 OneDrive 把它設成「檔案隨選／僅線上」，Chrome 啟動時可能讀不到檔案而載入失敗。請在檔案總管對 `PaperLens` 資料夾按右鍵 →「一律保留在此裝置上」，或乾脆把整個資料夾搬到 `C:\Users\user\PaperLens` 之類不會同步的位置，再重新載入一次。

Chrome 每次啟動會跳一個「停用開發人員模式擴充功能」的提醒泡泡，按 **取消** 就好，它不會真的停用，也不影響功能。

### 換一台電腦

跑 `powershell -ExecutionPolicy Bypass -File tools\build.ps1` 會在 `dist\` 產生一個 ZIP，拿到另一台電腦解壓縮後一樣用「載入未封裝項目」即可。註解與設定是各機器獨立的，可以用設定頁的「匯出全部註解」搬過去。

## 用法

| 動作 | 怎麼做 |
|---|---|
| 開啟／關閉對照 | 點工具列圖示，或按 `Alt+Shift+T` |
| 翻譯全文 | 頂端工具列的「翻譯全文」 |
| 畫重點 | 直接用滑鼠選取文字 → 跳出色票，點一下 |
| 寫心得 | 選取文字 → 「✎ 心得」 |
| AI 解釋這段 | 選取文字 → 「✨ AI 解釋」 |
| 快速標記 | 選好文字按 `Alt+Shift+H` |
| 看所有註解 | 工具列「註解」開側欄，點任一則會跳到原位 |
| 匯出 PDF | 工具列「匯出 PDF」→ 新分頁 → 「列印 / 另存 PDF」 |
| 調左右比例 | 拖中間的分隔線，雙擊回到 50% |

**預設是「捲到哪翻到哪」**，所以很長的論文一開啟就能讀，不用等全文翻完。要整篇翻好（例如準備匯出 PDF）就按「翻譯全文」。

## 翻譯引擎

依序嘗試，前一個失敗自動換下一個（順序可在設定頁調整）：

| 引擎 | 費用 | 特性 |
|---|---|---|
| **Chrome 內建 AI** | 免費 | 離線、無額度上限。第一次要下載模型（幾十 MB），下載期間會自動先用線上引擎頂著，好了之後自動接手 |
| **Edge／Bing** | 免費、免金鑰 | 長句品質好；Edge 憑證失效時自動改走 Bing 介面 |
| **Google 翻譯** | 免費、免金鑰 | 品質穩定，但同一個 IP 大量請求會被暫時限流 |
| **Gemini API** | 選用 | 到 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 免費申請金鑰貼進設定頁。學術術語翻得最好，「AI 解釋」也最完整 |

翻過的段落會存在本機快取，同一篇再開不會重翻。

### AI 解釋這段

優先用你填的 Gemini 金鑰。沒填就用 Chrome 內建的 Gemini Nano —— 它只能輸出英文，所以會先寫英文解釋再自動翻成中文，全程免費離線。

到設定頁按 **「測試引擎可用性」** 可以一次看到每個引擎現在能不能用、延遲多少。

## PDF 匯出

匯出頁可以現場調整再列印：

- **版面** — 左原文右譯文 / 只要譯文 / 只要原文
- **紙張** — A4 橫向（推薦，對照才不會太擠）/ A4 直向 / A3 橫向
- **圖表** — 跨欄放大（省紙，用譯文版的圖說）/ 跟文字一樣並排
- **只留正文** — 濾掉導覽列、頁尾、側欄
- **附上我的註解** — 文末附螢光標記、心得與 AI 解釋
- **內嵌圖片** — 把圖抓成 data URL 內嵌，避免期刊防盜連導致列印缺圖

按「列印 / 另存 PDF」後，在列印視窗的**目的地**選「另存為 PDF」。想保留螢光筆顏色，要展開「更多設定」勾選**背景圖形**。

## 資料存在哪

全部在本機 `chrome.storage.local`：翻譯快取、螢光筆與心得、設定、Gemini 金鑰。沒有任何伺服器、沒有帳號。

設定頁可以**匯出全部註解成 JSON**（建議偶爾備份）以及匯入。同一篇文獻的註解用去掉追蹤參數後的網址當索引，所以從不同來源連過去也認得出來。

## 已知限制

- **掃描版 PDF 無法翻譯**（整頁是圖、沒有文字層，需要 OCR）。有文字層的 PDF 都可以。
- 便利貼在匯出時是文字附錄，不是貼在原位（手寫圈選、箭頭、畫筆則會原位印出）。
- 譯文欄的**一般連結會變成純文字**（引用標記如 `[12]`、上下標、公式、程式碼、圖片都會完整保留）。這是為了讓整句一起送翻、語意才完整的取捨；原文欄永遠是完好的。
- 右欄是左欄的 DOM 深拷貝，所以頁面上的 `id` 會短暫重複。靜態閱讀不受影響，但少數重度依賴 JS 的網站互動可能失常——關掉對照就會完全還原。
- 嵌入式播放器、廣告 iframe 在右欄換成佔位框，不會重複載入。
- `chrome://`、Chrome 線上應用程式商店、瀏覽器內建 PDF 檢視器這些頁面受保護，無法注入。

## 開發者備註

純 JavaScript，沒有建置步驟，改完存檔到 `chrome://extensions` 按重新載入即可。

```
manifest.json          MV3 設定
background.js          service worker：注入、遠端翻譯代理、內建 AI 的 worker 側
shared/defaults.js     預設值與各引擎語言代碼對照
shared/localai.js      Chrome 內建 Translator / LanguageDetector / LanguageModel 封裝
content/core.js        區塊偵測、佔位符（保護連結公式）、翻譯快取
content/split.js       分欄、工具列、捲動同步、拖曳分隔線
content/translate.js   排隊、批次送翻、引擎備援、回填
content/annotate.js    螢光筆、心得、AI 解釋、側欄
content/export.js      收集左右對照內容
content/boot.js        入口與訊息處理
export/                PDF 匯出頁
options/ popup/        設定頁與彈出視窗
tools/make-icons.js    產生圖示（node tools/make-icons.js）
tools/devserver.js     開發用靜態伺服器
tools/testbed.html     離線測試台：用假的 chrome API 把 content script 跑在一篇假論文上
```

### 測試台

不用裝進 Chrome 就能驗證分欄、區塊偵測、註解錨定、匯出收集：

```bash
node tools/devserver.js
```

開 <http://localhost:5177/tools/testbed.html>，右下角有控制面板。
按「收集匯出內容」之後，<http://localhost:5177/export/export.html?testbed=1> 可以直接預覽 PDF 版面。
